# UBS — сайт (EN / RU / KK)

Статический сайт UBS Establishment, перенесённый с Tilda в чистый HTML/CSS/JS без внешних
зависимостей. Дизайн, структура и анимации повторяют оригинал; добавлены русская и казахская
версии, адаптация под планшеты и правки заказчика (см. [CHANGES.md](CHANGES.md)).

## Что где лежит

```
docs/                 ← готовый сайт: именно эту папку загружают на хостинг
  index.html          английская версия (главная)
  about-ubs/ …        страницы на английском
  ru/ …               русская версия
  kk/ …               казахская версия
  assets/css/         base.css (основа), site.css (компоненты), blocks.css + page-*.css
                      (позиционированные секции), i18n.css (поправки под RU/KK)
  assets/js/site.js   анимации, слайдеры, меню, попап, формы (без библиотек)
  assets/img|fonts|icons
  send.php            отправка заявок с форм на почту (PHP, работает на hoster.kz)
  .htaccess           редиректы со старых адресов, кэш, сжатие, 404
  sitemap.xml, robots.txt, 404.html, favicon.ico
tools/                генератор сайта (Python) и служебные скрипты
src/orig/             исходные страницы Tilda (источник позиций и стилей)
src/i18n/ru.json, kk.json   переводы (английский текст → перевод)
src/fonts/            исходные файлы шрифта TRYGrtsk (до добавления казахских букв)
```

## Загрузка на hoster.kz

1. В панели hoster.kz откройте «Файловый менеджер» (или подключитесь по FTP).
2. Загрузите **содержимое** папки `docs/` в корень сайта (`public_html` / `www`), включая
   скрытый файл `.htaccess`.
3. В `send.php` проверьте адреса: `MAIL_TO` — куда приходят заявки, `MAIL_FROM` — ящик
   на домене сайта (создайте его в панели, иначе письма могут попадать в спам).
4. После выпуска SSL-сертификата раскомментируйте в `.htaccess` блок «Force HTTPS».
5. Если домен не `ubsystem.kz`, поменяйте `SITE_URL` в `tools/build.py` и пересоберите
   (или поправьте `sitemap.xml` и `robots.txt` вручную).

Сайт работает и из подпапки, и с корня: все ссылки относительные.

## Как менять тексты

* Переводы — в `src/i18n/ru.json` и `src/i18n/kk.json` (ключ — английский текст).
* Тексты трёх новых услуг — в `tools/services.py`.
* Контакты, команда, логотипы партнёров — в `tools/components.py` (`TEAM`, `LANDLINE`, `BRANDS`).
* Правки формулировок по замечаниям заказчика — в `tools/edits.py` (`REPLACE`).
* Фото основателя: положите файл в `docs/assets/img/` и укажите его в `FOUNDER_PHOTO`
  в `tools/edits.py`.

После изменений пересоберите сайт:

```bash
python3 tools/build.py
```

Нужен Python 3 и пакет `beautifulsoup4` + `lxml`.

Для точной раскладки RU/KK генератор использует замеры высот английских блоков
(`src/heights.json`). Если меняли английские тексты или вёрстку секций, обновите замеры
(нужен Node.js и Playwright), затем пересоберите ещё раз:

```bash
python3 -m http.server 8765 -d docs
```

```bash
node tools/measure.mjs http://localhost:8765/
```

## Локальный просмотр

```bash
python3 -m http.server 8765 -d docs
```

и откройте http://localhost:8765. Формы локально и на GitHub Pages не отправляются — для
них нужен PHP, который есть на hoster.kz.
